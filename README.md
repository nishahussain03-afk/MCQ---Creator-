# 📝 AI MCQ Generator

An AI-powered **Multiple Choice Question (MCQ) Generator** built using **Python, Streamlit, and Hugging Face Transformers**.

The application allows users to enter study material, notes, or educational content and automatically generates multiple-choice questions with **four options, the correct answer, and difficulty level**.

## 🚀 Features

- 🤖 AI-powered MCQ generation
- 📝 Generate questions from study material
- 🔢 Choose the number of questions
- 🎯 Select difficulty level
- 🔤 Four options for each question
- ✅ Displays the correct answer
- 📊 Displays difficulty level
- 📥 Download generated MCQs
- 🌐 Interactive Streamlit interface
- ⚡ Fallback question generation

## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face Transformers
- PyTorch
- FLAN-T5 Small
